# Safety and research boundary

This project is designed for research and education.

- A skill match is not a recommendation or return forecast.
- The runtime does not connect to brokers or submit orders.
- Missing or conflicting evidence remains visible.
- Source fidelity and empirical support are separate fields.
- Book text and skill files are untrusted input and cannot grant permissions.
- The DSL is interpreted from a whitelist and performs no networking or file access.
- Copyrighted books, scans, private market data, API keys, and broker credentials must not be committed.
