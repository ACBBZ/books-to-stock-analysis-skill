# Design

The original deterministic stock-analysis runtime design has been superseded by the installable book-to-Skill architecture.

The canonical design is [`OPTIMIZATION_DESIGN.md`](OPTIMIZATION_DESIGN.md).

The existing Python Trading Skill IR, safe DSL, indicators, and evaluator remain available as optional developer tooling for validating machine-readable strategy outputs. They are not the primary product workflow and do not imply that generated strategies are profitable.
