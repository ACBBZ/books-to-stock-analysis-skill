# Copyright-Safe Export Policy

## Default export

Generated packs may contain:

- bibliographic metadata;
- chapter and page references;
- concise derived descriptions;
- original skill instructions;
- structured source maps;
- independently reconstructed diagrams that are clearly labeled as reconstructions;
- short quotations only when necessary and legally appropriate.

Generated packs must not contain by default:

- the source book;
- complete page scans;
- long continuous quotations;
- a chapter-by-chapter reproduction that substitutes for the book;
- third-party images copied from the source;
- private notes or credentials not needed by the skill.

## Reports

`reports/copyright-report.yaml` must state whether the output contains source files, page images, long quotations, reconstructed diagrams, or externally licensed material.

## Local private sources

Commercial books remain in the user's local workspace. The generator should record file hashes and source locations without copying the source into independently installable skill directories.
